# 第 8 课 RCU（LR-0011）

**Status:** active

## 决策
第 8 课讲 RCU（§B.2.12），同时补 §B.2.3 屏障 和 §B.2.6 禁抢占——三者天然咬合：RCU 读侧免锁的根基就是 preempt_disable，rcu_dereference 的精髓就是恰好够用的内存顺序。

## 核验（不靠记忆）
- **读侧免锁**：非抢占内核里 rcu_read_lock ≈ preempt_disable + 编译器屏障，无原子指令、无缓存抖动。
- **rcu_dereference / rcu_assign_pointer**：成对处理发布-订阅顺序。assign 换指针前插写屏障；dereference 取指针后保证先取指针再取数据（Alpha 需硬件屏障，其他架构靠地址依赖）。
- **宽限期**：所有 CPU 经过一次静止状态的时间窗；synchronize_rcu 阻塞等宽限期，返回后安全 kfree 旧数据。
- **哲学**：不让读者付费，让写者付费。读极多写极少才合适。

## 三组件讲法
1. RCU 主线：核心思想（写者付费）+ 时间轴图 + 读侧三件套 + 写侧三件套 + 宽限期 + vs seqlock。
2. §B.2.6 禁抢占：在"读侧为什么免锁"处自然引入（rcu_read_lock ≈ preempt_disable）。
3. §B.2.3 屏障：在"rcu_assign/dereference 为什么成对"处自然引入（发布-订阅顺序）。

## 实验
`bt_rcu.c`：RCU 保护全局链表头，reader() 零锁遍历，演示读侧零开销。WSL2 可跑。
