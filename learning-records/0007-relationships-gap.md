## 从书里读到的权威内容(已用 pdftotext 核对)
1. **一对一**:结构体之间用"指针"或"内嵌(包含)"两种方式表达。内嵌体现关系清晰、方便管理(书用"男人和妻子《婚姻法》一对一"作例子)。
2. **一对多**:最简单是单向链表(leaf 含 next 指针);需要双向遍历/增删改 → list_head / hlist_head / rb_root。
3. **多对多**:**不能用简单地把 list_head 嵌进 student 实现**(因为一个 list_head 节点只能属于一条链)。书的方案是独立一个 `connection` 辅助结构体:
   ```c
   struct connection {
       struct list_head s_node;   // 挂到 teacher 的学生链
       struct list_head t_node;   // 挂到 student 的老师链
       struct teacher  *teacher;
       struct student  *student;
   };
   ```
   - **只有相互的关系才能合并两个 node**:老师↔学生是相互的(可合并);粉丝↔偶像的单向暗恋不能合并(会造成空间浪费或逻辑混乱)。
   - 真实用例:input 子系统的 input_handle(本质同构)。
