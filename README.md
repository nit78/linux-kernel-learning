# 图解 Linux 内核 · 学习课程

> 从**驱动移植**走向**内核 / BSP 工程师**。基于《图解Linux内核（基于 6.x）》（姜亚华，机械工业出版社，2024，对应 Linux 6.2）。
>
> 每课短小可一次完成：先给最小够用的知识，立刻进入一个能跑起来的动手实验（`.ko` 模块 / 内核命令），再用测验巩固。沿用「MCU 思维 ↔ 内核思维」对照，把裸机经验迁移成内核直觉。
